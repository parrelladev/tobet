# Tobet D10

Um rolador de dados d10 em HTML, CSS e JavaScript, com visual inspirado na marca fictícia Tobet da sua mesa de RPG.

## Como executar

1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Escolha a quantidade de dados e o modificador.
4. Clique em **Rolar os dados** ou pressione a barra de espaço.

O histórico das últimas 12 rolagens fica salvo no navegador usando `localStorage`.

## Arquivos

- `index.html` — estrutura da página
- `styles.css` — identidade visual e responsividade
- `script.js` — rolagens, animações e histórico

## Observação

A fonte é carregada pelo Google Fonts. Sem internet, o site continua funcionando com as fontes alternativas locais.
